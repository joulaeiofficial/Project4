# IT Request Monitor

برنامه‌ی ویندوز برای اطلاع‌رسانی فوری **درخواست‌های جدید پشتیبانی IT**.

برنامه در پس‌زمینه (کنار ساعت) اجرا می‌شود، هر چند ثانیه سرور را چک می‌کند و وقتی درخواست جدیدی ثبت شود، یک **نوتیفیکیشن ویندوز** همراه با صدا نشان می‌دهد. با کلیک روی نوتیفیکیشن، صفحه‌ی ورود مدیریت در Chrome باز می‌شود.

## برنامه چه کارهایی می‌کند؟

- هر چند ثانیه یک بار (پیش‌فرض ۱۵ ثانیه) از سرور آخرین درخواست را می‌گیرد.
- اگر شماره‌ی درخواست از دفعه‌ی قبل بزرگ‌تر باشد، نوتیفیکیشن با عنوان و زمان درخواست (به وقت تهران) نشان می‌دهد و بوق می‌زند.
- با بستن پنجره، برنامه بسته نمی‌شود و در کنار ساعت می‌ماند.
- می‌تواند همراه روشن شدن ویندوز، مخفی اجرا شود.
- همه‌ی رخدادها در پنجره و در یک فایل لاگ ثبت می‌شوند.

## سازگاری با پورتال داخلی فاوا

این برنامه با پروژه‌ی [پورتال داخلی فاوا — فن‌آوران طرح جامع](https://github.com/joulaeiofficial/Project2) سازگار است و به‌عنوان مکمل آن کار می‌کند.

- پورتال (PHP + SQLite روی IIS) درخواست‌های پشتیبانی IT را از طریق صفحه‌ی `itrequest.php` ثبت و در جدول `it_requests` نگه‌داری می‌کند.
- فایل `it_status.php` در همان پورتال، آخرین درخواست ثبت‌شده را همراه با کلید API برمی‌گرداند و **همان آدرسی است که باید در «آدرس سرور» این برنامه وارد کنید**.
- کلید API تعریف‌شده در `it_status.php` همان **رمز عبور** این برنامه است.
- با کلیک روی نوتیفیکیشن، صفحه‌ی ورود پنل مدیریت پورتال (`admin.php`) باز می‌شود تا درخواست را بررسی کنید.

> برای استفاده، پورتال باید روی سرور داخلی نصب و اجرا باشد. راه‌اندازی آن در README خودِ پروژه‌ی پورتال توضیح داده شده است.

### توسعه برای پروژه‌های دیگر

این برنامه به پورتال فاوا وابسته نیست و می‌توان آن را برای پروژه‌های دیگر هم توسعه داد. دست توسعه برای این کار کاملاً باز است. هر سامانه‌ای که یک آدرس ساده برای دریافت «آخرین درخواست» داشته باشد، با کمی تغییر در `main.js` قابل اتصال است:

- آدرس سرور و کلید API از داخل برنامه تنظیم می‌شوند و به یک پروژه‌ی خاص قفل نیستند.
- فقط کافی است سرور شماره‌ی آخرین درخواست، عنوان و زمان ثبت آن را برگرداند. اگر ساختار پاسخ فرق دارد، بخش خواندن پاسخ در `main.js` را مطابق آن تغییر دهید.
- می‌توان برای چند پروژه یا چند سرور همزمان نظارت تعریف کرد و عنوان نوتیفیکیشن را برای هر پروژه جدا نوشت.

## نصب و اجرا

به [Node.js](https://nodejs.org) (نسخه‌ی ۱۸ یا بالاتر) نیاز دارید.

```bash
npm install
npm start
```

## ساخت فایل نصبی (Setup)

```bash
npm run dist
```

فایل نصبی ویندوز (NSIS) داخل پوشه‌ی `dist` ساخته می‌شود. هنگام نصب می‌توانید مسیر نصب را انتخاب کنید.

> اگر فایل `renderer/style.css` را تغییر می‌دهید یا کلاس‌های Tailwind جدید اضافه می‌کنید، با `npm run build-css` دوباره بسازیدش (دستور `dist` خودش این کار را هم می‌کند).

## نحوه‌ی استفاده

1. برنامه را باز کنید.
2. **آدرس سرور** (فایل `it_status.php`) را بررسی کنید. آدرس پیش‌فرض داخل برنامه هست.
3. **رمز عبور** (کلید API) را وارد کنید.
4. در صورت نیاز **فاصله‌ی بررسی** را بر حسب ثانیه تغییر دهید.
5. اول «تست اتصال» را بزنید تا مطمئن شوید سرور جواب می‌دهد، بعد «شروع» را بزنید.
6. با «تست نوتیفیکیشن» می‌توانید ببینید اعلان و صدا درست کار می‌کنند.

حالا می‌توانید پنجره را ببندید. برنامه کنار ساعت می‌ماند. برای خروج کامل، روی آیکون کنار ساعت راست‌کلیک کنید و «خروج کامل» را بزنید.

### اجرای خودکار با ویندوز

در بار اول اجرا، این گزینه خودکار روشن می‌شود و برنامه هنگام ورود به ویندوز مخفی اجرا می‌شود. از داخل برنامه می‌توانید خاموشش کنید.

⚠️ **رمز عبور ذخیره نمی‌شود.** بعد از هر بار روشن شدن ویندوز، برنامه مخفی باز می‌شود ولی نظارت شروع نمی‌کند؛ باید پنجره را از کنار ساعت باز کنید، رمز را وارد کنید و «شروع» را بزنید. فقط آدرس سرور و فاصله‌ی بررسی ذخیره می‌شوند.

## فایل‌ها و لاگ

برنامه این دو فایل را در پوشه‌ی داده‌ی کاربر (`%APPDATA%\it-alert-client`) می‌سازد:

| فایل | محتوا |
|---|---|
| `it_alert_client_config.json` | آدرس سرور و فاصله‌ی بررسی |
| `it_alerts_client.log` | لاگ رخدادها (با دکمه‌ی «باز کردن فایل لاگ» باز می‌شود) |

## ساختار پروژه

```text
main.js            منطق اصلی: پایش سرور، نوتیفیکیشن، آیکون کنار ساعت، تنظیمات
preload.js         پل امن بین برنامه و رابط کاربری
renderer/          رابط کاربری (HTML + Tailwind CSS v4 + JS)
assets/            آیکون‌های برنامه
```

## نکته‌های امنیتی

- ارتباط با سرور با گواهی SSL خودامضا (self-signed) هم کار می‌کند، چون سایت داخلی است. برای همین **اعتبارسنجی گواهی در کد غیرفعال است**. این برنامه را فقط برای همین سرور داخلی استفاده کنید و اگر سرور گواهی معتبر گرفت، `rejectUnauthorized: false` را در `main.js` بردارید.
- کلید API روی دیسک ذخیره نمی‌شود و در URL درخواست به سرور ارسال می‌شود (`?key=...`)؛ پس بهتر است فقط روی شبکه‌ی داخلی یا HTTPS استفاده شود.

## مشکل دارید؟

- **نوتیفیکیشن نمی‌آید:** مطمئن شوید Focus Assist / حالت «مزاحم نشوید» ویندوز خاموش است و با «تست نوتیفیکیشن» امتحان کنید.
- **«خطا در اتصال به سرور»:** آدرس سرور و اتصال شبکه را بررسی کنید، سپس «تست اتصال» بزنید. جزئیات خطا در بخش «رخدادها» نوشته می‌شود.
- **کلیک روی نوتیفیکیشن Chrome را باز نمی‌کند:** اگر Chrome پیدا نشود، لینک در مرورگر پیش‌فرض باز می‌شود.
- **برنامه بسته نمی‌شود:** دکمه‌ی ✕ فقط پنجره را مخفی می‌کند. از منوی آیکون کنار ساعت «خروج کامل» را بزنید.
